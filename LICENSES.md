# License scope

This hub brings together contributions for independently licensed upstream projects.
It does not apply a blanket license or relicense upstream-derived patches.

- Cyclopts: Apache-2.0, [exact upstream license](projects/cyclopts/LICENSE.upstream)
  and [attribution](projects/cyclopts/ATTRIBUTION.md)
- Mitty: MIT, [exact upstream license](projects/mitty/LICENSE.upstream)
  and [attribution](projects/mitty/ATTRIBUTION.md)
- LLM: Apache-2.0, [exact upstream license](projects/llm/LICENSE.upstream)
  and [attribution](projects/llm/ATTRIBUTION.md)

The license texts were copied from each manifest's exact baseline commit and are
hash-checked. Patches retain upstream context and visibly identify modifications.
No separate repository-wide license declaration is made for the hub's own tooling
and documentation. This file is an attribution and scope record, not legal advice.
